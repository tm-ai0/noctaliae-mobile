## 🎯 RÉSUMÉ ULTRA-RAPIDE

**Ancien prompt** : Poétique, symbolique, mystique
**Nouveau prompt** : Scientifique, factuel, neurocognitif

**Principes clés** :
- Rêve = activité cognitive (pas symbolique)
- 65% continuité avec la veille
- 82% négatifs (adaptatif)
- Simulation de menaces
- Créativité via associations

**Éviter** :
- Interprétations symboliques littérales
- Psychanalyse freudienne
- Prédictions
- Affirmations non scientifiques

**Déploiement** :
1. Connexion SSH au serveur
2. Localiser fichier backend
3. Remplacer SYSTEM_PROMPT
4. Redémarrer service
5. Tester
