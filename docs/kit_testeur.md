## 🌐 OÙ HÉBERGER LA LANDING PAGE ?

**Options gratuites :**

1. **GitHub Pages** (recommandé)
   - Crée un repo `noctaliae-beta`
   - Upload `index.html`
   - Active GitHub Pages dans Settings
   - URL : `tonusername.github.io/noctaliae-beta`

2. **Netlify**
   - Drop le fichier HTML
   - URL : `random-name.netlify.app`

3. **Vercel**
   - Même principe
   - URL : `project.vercel.app`

**Pour l'APK :**
- Héberge sur le même repo GitHub (dans /downloads/)
- Ou utilise le lien direct d'EAS Build
