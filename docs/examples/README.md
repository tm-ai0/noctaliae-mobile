# 📝 Code Examples

Ce dossier contient des exemples de code pour les fonctionnalités clés de Noctaliæ.

## Fichiers disponibles :

- **CODE_RATE_LIMITING.js** : Implémentation du système de rate limiting
- **CODE_secureStorageService.js** : Service de stockage sécurisé avec Expo SecureStore

Ces exemples sont destinés aux développeurs qui souhaitent comprendre
ou contribuer aux fonctionnalités de sécurité et de limitation de l'app.
